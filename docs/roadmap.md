## 二、缺失能力（作为"个人电脑"还差什么）

| 能力 | 说明 | 对应模块 |
|------|------|---------|
| **文件系统** | 读写文件、目录管理、文件搜索 | limb扩展 |

| **浏览器** | 网页访问、信息抓取、表单填写 | sense扩展 |

## 三、实施路线图

### Phase 1：补齐核心（1-2周）
让OpenSoul成为一台能用的"电脑"

1. **terminal模块** — shell命令执行、进程管理
2. **file_system模块** — 文件读写、目录管理、搜索
3. **browser模块** — 网页访问、信息抓取
4. **tool_registry** — 工具发现、注册、调用
5. **context_manager** — 上下文窗口管理

### Phase 2：让Agent"活"起来（2-3周）
从被动执行变为主动智能

1. **主动行为引擎** — 观察→判断→行动循环
2. **长期学习系统** — 经验积累→模式提取→行为优化
3. **工具链编排** — 多工具串联、错误恢复、回滚
4. **SoulBrain集成** — 认知层接入所有执行流程
5. **多租户完善** — 所有模块tenant_id隔离

### Phase 3：高级智能（3-4周）
真正的"灵魂"

1. **自我进化** — 自动优化prompt和策略
2. **情感驱动** — 情绪影响决策权重
3. **元认知** — 自我反思、自我纠错
4. **多Agent协作** — 分工、协调、合并
5. **创造力引擎** — 生成新方案

## 四、当前最紧迫的问题

1. **认知层没有接入执行流程** — SoulBrain只是API，没有被limb/will实际调用
2. **记忆存JSON文件** — 应该存SQLite，和已有hippo统一
3. **terminal/文件系统缺失** — Agent不能操作电脑
4. **主动行为缺失** — 只能被动响应，不能主动行动
5. **工具发现缺失** — 不能自主学习新工具

**建议从Phase 1开始：先让OpenSoul能操作电脑（terminal + file_system），然后接入SoulBrain认知层。**
