# OpenSoul Scripts

## seed_builtin_courses.py

Seeds the OpenLearn system with built-in courses about the OpenSoulmate ecosystem.

```bash
python scripts/seed_builtin_courses.py
```

Courses created:
1. **OpenSoulmate 快速入门** — 3 chapters covering core concepts, deployment, and knowledge management
2. **25组件架构详解** — 3 chapters covering core layer, infrastructure layer, and advanced ecosystem layer
3. **Agent 开发实战** — 2 chapters covering agent basics and multi-agent collaboration

Each chapter includes Markdown content and quiz questions with explanations.

> Note: After running the script, restart OpenSoul to pick up the new courses.
